The fact, or, when there is none, the value of compute, run as the one writer of the field's owner (see Sharing.claim) and stored. The field is read again inside the claim first, since another thread may have stored the value meanwhile. Another thread waits for an owner's computation at the claim, so compute is entered again only by its owner, re-entering its own computation: the place for a cycle test.
