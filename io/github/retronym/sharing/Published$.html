opaque type Acquired[S, F <: String, T]

The value of S's publisher F (S the owner's singleton type), loaded with acquire semantics: the evidence that a Payload of F is read after it (version.acquired, then text.after(snap)).

The value of S's publisher F (S the owner's singleton type), loaded with acquire semantics: the evidence that a Payload of F is read after it (version.acquired, then text.after(snap)).

It need not be used at once: a read after an acquire in program order still sees what the acquire made visible, so evidence that outlives its block is still sound.

opaque type Handle[O, F <: String]

The VarHandle of field F of class O, declared once, as a given in O's companion.

The VarHandle of field F of class O, declared once, as a given in O's companion.

Opaque over the handle itself, not a class holding it: C2 folds a handle in an object's field, as one in a static final field, and inlines getAcquire to the Unsafe intrinsic, but not one a field further away (measured: a class around the handle left the call uninlined, 8 times slower).

Type parameters

the field's name, as a literal type

opaque type Publishing

Evidence that a store runs inside a publishing block, before the release that ends it: what := on a Payload needs. A block's evidence may only be passed to := in it: the macro rejects any other use.
