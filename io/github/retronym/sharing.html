trait ClaimRegistry

Who holds the claims on keys when threads are concurrent. A claim is a reentrant lock per key, whose waits feed a wait-for graph for deadlock detection (PerKeyClaims), or the one coarse lock (CoarseLock).

Who holds the claims on keys when threads are concurrent. A claim is a reentrant lock per key, whose waits feed a wait-for graph for deadlock detection (PerKeyClaims), or the one coarse lock (CoarseLock).

Sharing.claim, Sharing.claimAt and Sharing.once call it in Mode.Concurrent (never in Mode.Batch). The owner of the shared state supplies one as a given, beside the Mode. The library states the contract, and provides the two shapes that fit it:

  • One coarse lock, a CoarseLock, for every key whose Sharing.ClaimKind says serialised threads take it: threads are serialised, and a claim is the lock.
  • A lock per key, PerKeyClaims, for parallel threads. Threads that claim different keys run side by side. A thread that would wait for a claim whose holder is, directly or through other claims, waiting for it closes a wait-for cycle. The registry reports that to a CycleHandler instead of deadlocking.

The contract: at most one thread holds the claim on a key at a time, and the holder claiming the same key again (re-entry) runs at once instead of waiting for itself.

class Claimant(val thread: Thread = ...)

A party that holds and waits for claims in PerKeyClaims: one per thread, or one per request that may move between threads. PerKeyClaims compares claimants by identity.

A party that holds and waits for claims in PerKeyClaims: one per thread, or one per request that may move between threads. PerKeyClaims compares claimants by identity.

PerKeyClaims detects deadlock on the wait-for graph, and picks a victim. When waiting for a claim would close a cycle (another claimant holds the claim, and is waiting, directly or through others, for one of this claimant's):

  • a claimant that canAbort is the victim: it throws Cancelled at once, so its claims unwind and its work is retried;
  • otherwise, while some party of the cycle can abort, it waits for that one to;
  • otherwise one party of the cycle (the same for every party, by a fixed order of their threads) reports it to the claim's cycle (a CycleHandler), once it has seen the same cycle at two looks.

This is detection, as in a database's lock manager, not prevention: wound-wait and wait-die (Rosenkrantz, Stearns and Lewis, 1978) order the parties by a timestamp so that no cycle forms, which would abort work that a cycle never threatened.

In the compiler a claimant typing a method body can abort (its request is retried), and one inside a signature's completion cannot: a cycle between signatures is a cyclic reference, reported as an error.

final class Mode(val concurrent: Boolean) extends AnyVal

Whether the state that Sharing's operations guard is shared between threads.

Whether the state that Sharing's operations guard is shared between threads.

The owner of the state chooses a mode when it is created and never changes it. The operations take the mode as a given, which the owner supplies from a final field:

class Universe(shared: Boolean):
  given Mode = if shared then Mode.Concurrent else Mode.Batch
  • Mode.Batch: one thread. Every operation is the plain code it wraps, with no locking, no claims and no allocation, so a program that never shares state pays nothing for being written against this library.
  • Mode.Concurrent: several threads. Operations take monitors or ask the ClaimRegistry for claims.

How concurrent threads take a claim (serialised under one coarse lock, or in parallel with a claim per key) is the registry's choice, not the mode's: the operations test only concurrent.

Representation

A value class over a Boolean, so that the test on a hot path is a field read and a branch, the code a plain Boolean field gives. An opaque type would add a load of its package object (the inliner's proxy for the opaque scope), and testing an Int would materialise a Boolean.

Value parameters

concurrent

true if the state is shared between threads

final class PerKeyClaims(currentClaimant: () => Claimant, cycles: CycleHandler) extends ClaimRegistry

A ClaimRegistry for parallel threads: a claim per key, so that work on different keys runs at once.

A ClaimRegistry for parallel threads: a claim per key, so that work on different keys runs at once.

A claim is its claimant's: reentrant for that claimant, and every other claimant that needs the key waits until the owner releases it, then looks at what the key guards again (computed, or left computable by an owner that unwound).

A wait that would close a cycle in the wait-for graph (each waiting claimant records the claim it waits on, Claimant.waitingOn; following the owners from the claim leads back to the waiter) is a dependency cycle, handled as Claimant says. The check runs at every slice of a wait, since another claimant's wait may start after this one's.

object Sharing

Operations on state shared between threads, with evidence types that make the guarded state reachable only from inside them.

Operations on state shared between threads, with evidence types that make the guarded state reachable only from inside them.

The state is shared only in Mode.Concurrent. In Mode.Batch it is touched by one thread, and every operation here is the plain code it wraps. Each operation that takes code to run is an inline def whose batch branch is that code as it was before concurrency: a call site compiles to a test of the given Mode (a final field of its owner) and the original expression, and allocates nothing. The concurrent branches call the ClaimRegistry, or take a monitor.

The owner of the state supplies two givens: the Mode, and a ClaimRegistry for the operations that claim.

Which operation, by what the state is

  • A lazy fact, computed once by one writer while other threads wait for it: a Once field (one reference, keyed by its owner, stored only by the library), once (a value read without a lock once it is there, keyed by any object) or claim (anything else). A ClaimKind is given beside the key's class and, for re-entry, a BlackHole. The writer's state is reached through methods that take the claim's evidence, Holds[key.type].
  • A short critical section over a collection or a few fields: a Guard whose fields are Guarded, or serialised and locking on another object's monitor. The guarded state is reached with Monitor[lock.type].
  • A value paired with the stamp it was computed at: Stamped, one immutable object in one field.
  • Fields that a reader may see without a lock, published by one field: Published and its Payloads, written with release and read with acquire semantics. Array slots: Publish.

The registry's strategy is the owner's: a CoarseLock serialises the threads, PerKeyClaims lets them run in parallel with a claim per key. Concurrency picks the mode and the registry together.

Evidence

Guarded state is reachable only through methods that take an evidence parameter (a Holds or a Monitor, below), in the manner of Clang's thread-safety REQUIRES annotations. Only the operations here can make evidence, so touching the state outside the claim or the lock does not compile. At run time the evidence is one shared object, so it costs nothing.

import io.github.retronym.sharing.*

class Symbol(name: String)(using Mode, ClaimRegistry):
  private var myInfo: Info | Null = null

  // private to the writer: reachable only with the claim's evidence
  private def store(i: Info)(using Sharing.Holds[this.type]): Unit = myInfo = i

  def info: Info =
    Sharing.once(this)(myInfo):
      val i = computeInfo()
      store(i)
      i

object Symbol:
  given Sharing.ClaimKind[Symbol] = Sharing.ClaimKind(What("computing info", null), lockWhenSerialised = true)

final class Stamped[+K, +T](val stamp: Int, val value: T)

A value with the stamp it was computed at, as one immutable object, held in one var of the cache's owner.

A value with the stamp it was computed at, as one immutable object, held in one var of the cache's owner.

Bloch's racy single-check idiom (Effective Java, Item 83) over an immutable holder (JCIP §3.4.2): a reader that misses computes and stores, and two may both compute; the holder's final fields (JLS §17.5) make that safe without a volatile.

A stamp says what the value was computed against: a generation of the inputs, a run, a version. The value is valid while its stamp is the current one.

Both fields are final, so a reader that loads the reference sees the pair whole, however it was published: no fences, no test of a Mode, and the same code with one thread or several. A writer replaces the stamped value. A reader can never see a current stamp with an older value, nor a stamp and a value from two writers. The price is an allocation per miss and a dependent load per hit (the owner's field, then the stamped value's).

sealed trait PerGeneration // the kind of stamp: a phantom type

class Library(using Stamp[PerGeneration]):
  private var exports: Stamped[PerGeneration, List[String]] = Stamped.Empty
  def exportedNames: List[String] =
    exports.cached:
      computeExports()

A stamp is an Int, never 0 for a current one: Stamped.Empty, what a field starts with, has stamp 0. K is the stamp's kind, a phantom type: the operations take the current stamp of that kind as a given Stamp[K], which the owner supplies (typically an inline given that reads a counter). A call site therefore names no stamp, and a field is never read with one kind of stamp and written with another.

opaque type Once[K, T <: AnyRef]

A field holding a lazy fact, computed once by the one writer of its owner while other threads wait for it: null until the value is stored, then the value.

A field holding a lazy fact, computed once by the one writer of its owner while other threads wait for it: null until the value is stored, then the value.

Opaque, so that a plain read or write of the field does not type-check: the value is stored only by get, after compute returns, inside the claim on the owner, with release semantics, and read with acquire semantics. The value is therefore safely published (JCIP §3.5): a reader that finds it sees what it refers to, with no further rule on how it is built. The discipline that Sharing.once leaves to the owner (a store only under the claim, the field the same on both sides, a value safely published) is the type's.

class Symbol(name: String)(using Mode, ClaimRegistry):
  private[mypkg] var myInfo: Once[this.type, Info] = Once.empty

  def info: Info = myInfo.get(computeInfo())

object Symbol:
  given Sharing.ClaimKind[Symbol] = Sharing.ClaimKind(What("computing info", null), lockWhenSerialised = true)
  val myInfoHandle: Published.Handle[Symbol, "myInfo"] = Published.handle
  given Published.Handle[Symbol, "myInfo"] = myInfoHandle

The key of the claim is the field's owner, the K of its type (this.type where it is declared), so that compute is given Holds[K], the evidence for the owner's other writer state (a Sharing.BlackHole, say). The field needs a Published.Handle, declared as for a Published field, and must not be private. A fact keyed by another object, or that is not one reference, is Sharing.once's or Sharing.claim's.

In Mode.Batch the accesses are plain, so a hit is a field read and a null test, as before concurrency; in Mode.Concurrent the read is an acquire.

opaque type Payload[O, F <: String, T]

A field published by its owner's Published field F: stored only in a publishing block of F (before its release), read only after an acquired of F on the same object, or with plain where an unordered read is the protocol (a hint checked again after).

A field published by its owner's Published field F: stored only in a publishing block of F (before its release), read only after an acquired of F on the same object, or with plain where an unordered read is the protocol (a hint checked again after).

class Entry:
  private[mypkg] var version: Published[Int] = Published(0)
  private var text: Payload[Entry, "version", String] = Payload("")

  def read(expected: Int): String | Null =
    val snap = version.acquired
    if snap.value == expected then text.after(snap) else null

  def write(v: Int, t: String): Unit =
    version.publishing(v):
      text := t

Each misuse is a compile error: a plain read or store of text, a store outside the block, a store in a block of another object's publisher, a read after another object's acquire, and the block's evidence kept past it.

opaque type Published[T]

A field that publishes others: a writer stores them, then this field with release semantics; a reader loads this field with acquire semantics, then them. The release store pairs with an acquire load that reads its value, so what was written before the store is visible after the load: message passing (the MP litmus test) through one field, without a lock, as Java's VarHandle.setRelease and getAcquire give, with the field named at compile time.

A field that publishes others: a writer stores them, then this field with release semantics; a reader loads this field with acquire semantics, then them. The release store pairs with an acquire load that reads its value, so what was written before the store is visible after the load: message passing (the MP litmus test) through one field, without a lock, as Java's VarHandle.setRelease and getAcquire give, with the field named at compile time.

These are release/acquire in the C++11 sense, which the VarHandle access modes adopt. JLS §17 gives happens-before only to volatiles, monitors and thread start and join; Doug Lea's "Using JDK 9 Memory Order Modes" describes these modes.

Opaque, so that a plain read or write of the field does not type-check: the only ways in are acquire, release and, where the protocol allows a plain access, plain and setPlain, named so that they can be found and counted.

class Entry:
  private[mypkg] var version: Published[Int] = Published(0)
  private var text: String = ""                      // published by `version`
  def read(expected: Int): String | Null = if version.acquire == expected then text else null
  def write(v: Int, t: String): Unit = { text = t; version.release(v) }

object Entry:
  val versionHandle: Published.Handle[Entry, "version"] = Published.handle
  given Published.Handle[Entry, "version"] = versionHandle

The handle is a val and the given a reference to it: an alias given computed in place is a lazy val, whose check every access would pay. The operations are macros: they take the field's owner and name from the call (this.version), and the field's VarHandle from the given Handle[Owner, "name"] declared in the owner's companion, so two fields of the same type have their own handles, chosen at compile time. A value class is stored as its underlying value, the field's erased type. The field must not be private: the compiler drops a private field that no code reads or writes but through the handle, so handle rejects one; private[pkg] is kept. Supported: Int, Long, Boolean, references, and value classes over them.

To have the compiler check the fields it publishes too, make them Payloads.
